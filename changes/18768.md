Allow delegating to the empty address, so an account can stop staking

Sending a stake delegation to the empty public key is no longer rejected. An account delegated to the empty address has no stake and cannot be selected to produce blocks, which gives delegators a way to opt out of staking without moving their funds. This is the first part of the unstaking work described in MIP 35.

Newly created accounts now start with no delegate instead of delegating to themselves, so an account does not stake until it delegates. Genesis ledger accounts are unaffected: any genesis account that does not name a delegate still delegates to itself, so existing networks keep the same stake distribution. The `delegate` field returned by GraphQL can now be null for an account that has never delegated.
