Serve libp2p helper pprof profiles only when LIBP2P_ENABLE_PPROF=true

With `--libp2p-metrics-port`, the libp2p helper also served Go pprof profiles on `/debug/pprof/` next to `/metrics`, without authentication and with no way to turn them off. The metrics port now serves only `/metrics` by default. To also serve `/debug/pprof/`, set the environment variable `LIBP2P_ENABLE_PPROF=true` for the daemon process.
