Rosetta `/search/transactions` searches by account no longer scan every user command. The archive schema gains indexes on `user_commands.fee_payer_id`, `source_id` and `receiver_id`, and the user-commands search query uses them. It also no longer copies every canonical block on each request. Existing archives can add the indexes without downtime with `src/app/archive/add_user_commands_account_indexes.sql`.
