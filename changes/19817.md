The archive `upgrade.sql` and `downgrade.sql` scripts now accept a database created from the current `create_schema.sql`. Before, `downgrade.sql` stopped on such a database with "Could not apply Migration to current protocol & migration version: (4.0.0, <NULL>)". The migration version of both scripts is now `0.0.4`, so pass `--migration-version 0.0.4` to the `verify-upgrade` command of the archive hardfork toolbox.
