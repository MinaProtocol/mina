Fail at startup when no node profile is set

Mina binaries used to fall back silently to the development profile when neither `MINA_PROFILE` nor `/etc/coda/build_config/PROFILE` was set, running with development constants such as a ledger depth of 10. They now exit at startup with an error instead. Installed packages and Docker images already provide the profile file; set `MINA_PROFILE` (`devnet`, `mainnet`, `lightnet` or `dev`) when running binaries built from source. The daemon also logs its profile and constraint constants at startup.
