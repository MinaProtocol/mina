The daemon and `mina libp2p generate-keypair` now find the libp2p helper (`coda-libp2p_helper`) in the directory of the `mina` binary on Linux. Before, that lookup checked `/proc/PID` and never matched, so a `mina` outside `PATH` could not start its helper. `mina libp2p generate-keypair` and `dump-keypair` now print the error when the helper cannot start, instead of exiting with code 20 and no output.
