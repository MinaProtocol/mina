Bump the transaction protocol version to 5 for the next hard fork

Daemons built from this release report protocol version `5.0.0`. A hard fork from a version 4 network now boots correctly on nodes that generated their own fork config (`advanced generate-hardfork-config` or `--hardfork-handling migrate-exit`); previously such nodes could exit at startup with `Could not find a ledger tar file for hash ...` when the fork did not change the transaction protocol version.
