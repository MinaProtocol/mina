Shrink the Docker images back to their 4.0.0 size

Since 4.0.1 every `mina-daemon`, `mina-archive`, `mina-rosetta` and `mina-delegation-verifier` image carried the complete set of CI-built Debian packages in two dead layers, which made the bookworm daemon image about 11 GB on disk instead of under 4 GB. The packages are now mounted only while they are installed, so the images contain only the installed software again.
