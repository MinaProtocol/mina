`mina-create-genesis --print-tarball-names` lists the ledger tarballs of a config

`mina-create-genesis --config-file <config> --print-tarball-names` prints, for each ledger of the config, the file name that the daemon looks for in `/var/lib/coda` and downloads from S3, and the file's expected SHA3-256 (`s3_data_hash`). Use it to fetch the tarballs of a network ahead of time. `--genesis-dir` and `--hash-output-file` are not needed in this mode.
