Speed up serving ledgers to bootstrapping peers

Nodes now send the accounts that syncing peers request straight from their ledger database, instead of decoding each account and encoding it again. Answering a request for 64 accounts takes about a third of the time for ordinary accounts, and up to roughly 200 times less for zkApp accounts with verification keys. This also stops a node that serves a peer's bootstrap from pausing its own block processing for tens of milliseconds per request.
