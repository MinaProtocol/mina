Add a native integration test engine and rename the Docker engine

`mina-test-executive` has a new `native` engine. It runs the same tests as the Docker engine, but starts `mina` and `mina-archive` binaries directly on the host. To run one test with binaries built from the checkout, use `make intgtest-native TEST=<test>`; see `docs/tests.md`. The native engine is for local runs only and has no CI job. The existing engine is renamed from `local` to `docker`: use `mina-test-executive docker <test> …` instead of `mina-test-executive local <test> …`.
