Fix block producers with many delegators producing no blocks

A block producer checks every delegator for every slot, to see whether it won the slot. With a very large number of delegators, or on networks with short slots, checking a slot could take longer than the slot itself. The node then fell further behind with every slot, only discovered its wins after those slots had passed, and stopped producing blocks entirely. Each slot's check now stops in time for the block producer to use the result. A block producer that falls behind keeps producing blocks, using the best winner it found before the cut-off, while block producers that keep up are unaffected.
