Add --hardfork-handover flag to the archive node for hardfork handover

Archive nodes that take over from a hardfork can now pass `--hardfork-handover` (or set `MINA_ARCHIVE_HARDFORK_HANDOVER`) together with `--config-file`. The genesis ledger from the config file is then written to `genesis_accounts` at the genesis block height, so the archive database holds the fork's starting state. Without `--config-file` the flag has no effect and a warning is logged.
