Write the genesis ledger to genesis_accounts in the archive node

With `--config-file`, the archive node stores the config's genesis block (canonical, as the daemon would) and writes the genesis ledger to the `genesis_accounts` table at the genesis height, instead of one `accounts_accessed` row per account. An interrupted write is resumed. The archive node stops, and overwrites nothing, when the database holds another genesis block at that height, a different ledger hash, a genesis block that is not canonical, or another ledger in `genesis_accounts` at that height, and when the database has no `genesis_accounts` table (run `upgrade.sql`).

`--legacy-genesis-accounts` writes the genesis ledger to `accounts_accessed` as before.
