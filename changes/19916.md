Add protocol versions to blocks in the GraphQL API

GraphQL blocks now have `currentProtocolVersion`, the version a block was produced under, and `proposedProtocolVersion`, the version its block producer signals (null if it signals none). Querying `bestChain` for these fields shows what share of recent blocks come from upgraded block producers. Block producers set the proposed version themselves, and the block proof doesn't cover it, so treat it as an indication rather than a guarantee.
