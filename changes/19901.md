Check every block's protocol state independently of its proof

Nodes now rebuild each incoming block's protocol state from its parent and its contents, and reject the block if anything differs from the rebuild. Only the values a block producer chooses, such as the block creator, coinbase receiver, VRF output and timestamp, are taken from the block. The block proof already guarantees all of this, so valid blocks are unaffected. The extra check adds well under a millisecond in costs per block, but serves as protection in depth against a future weakness in the proof system, for example against quantum computers.
