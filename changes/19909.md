delegation_verify now requires the submitted SNARK work to belong to the submitted block

The stateless verifier used by the delegation program checked that an attached SNARK work proof was valid and signed for the submitter and fee, but not that the proved transaction came from the block in the submission. One valid proof could therefore be reused for later submissions. The verifier now rejects SNARK work whose target ledger is not the staged ledger of the submitted block. Submissions produced by a Mina node are unaffected.
