Build Mina with OCaml 5.3

The node is now compiled with OCaml 5.3 and a newer set of Jane Street
libraries. Consensus, wire formats and on-disk data are unchanged, and no action
is needed when upgrading.

One capability regresses: requesting an allocation trace by setting the
`MEMTRACE` environment variable no longer works, because the underlying
in-process tracing is not supported on OCaml 5's runtime. Reading and writing
existing trace files is unaffected.
