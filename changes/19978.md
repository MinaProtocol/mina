Remove the `zkapp_version` field from accounts

Nothing ever set this field, so it was always zero. It no longer appears in accounts in exported ledgers, runtime configs, or precomputed blocks, and tools that read those accounts should stop expecting it. Existing runtime configs that include the field still load, and it is ignored.

The field also leaves the account hash, which changes the hash of a zkApp account that has received a proved state update or dispatched actions.
