Add release stages that package and publish Bookworm arm64 Debian packages for the Lightnet Docker images

A release can now package Bookworm arm64 `mina-devnet-generic`, `mina-archive-devnet` and `mina-logproc`, with their dependencies, and publish them to the release repositories (pipeline filters `PackagingArm64Lightnet` and `PublishArm64Lightnet`). The o1-labs/mina-lightnet-docker release images install these packages, so with them the images can be built for arm64 as well as amd64. Release packaging stays amd64 only otherwise. The release package selection now fails when a package it selects is in the folder for two architectures, instead of publishing one of them unselected.
