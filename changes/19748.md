archive_hardfork_toolbox: `load-genesis-accounts` replaces `populate-genesis-accounts`

The new command writes the genesis ledger of a runtime config to `genesis_accounts`, at the height of the config's genesis block. It takes `--config-file` and `--chunk-size` (default 5000), continues an interrupted write, and prints JSON. `populate-genesis-accounts` and its `--chunks-length` flag are removed; to add the genesis block's `accounts_accessed`, start the archive with the fork's `--config-file`.
