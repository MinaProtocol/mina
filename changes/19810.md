Add a transactionPoolStatus GraphQL query

The new `transactionPoolStatus` query reports how many commands are in the node's transaction pool (`size`), how many it holds before evicting the lowest-fee ones (`maxSize`), and the lowest fee per weight unit currently in the pool (`minimumFeePerWeightUnit`), which a new command must beat once the pool is full. Transaction submitters can poll it cheaply to slow down before their commands start being evicted. The `mina-batch-txn` load-testing tool now uses it to pause while the pool is nearly full, and resends commands that were evicted anyway instead of stalling.
