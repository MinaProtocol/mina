Add a command that tallies the protocol versions signalled by block producers

`mina advanced protocol-version-signals` lists, for each protocol version that block producers propose in the best chain's blocks, how many blocks signal it, their share, and how many distinct producers. Use `--max-length` to count only the most recent blocks and `--json` for machine-readable output. Blocks are won in proportion to stake, so a version's share of blocks estimates its share of block-producing stake.
