Change the version of zkApp transaction IDs

The Base64 transaction ID of a zkApp command, as returned in the GraphQL `id` field, now carries version 3, so its contents differ from those of earlier IDs. Tools that store or compare these IDs should expect this. Transaction hashes are unchanged, and remain the stable way to identify a transaction.

`mina advanced hash-transaction` now computes the correct hash from these new zkApp transaction IDs.
