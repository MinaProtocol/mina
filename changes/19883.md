Stop mina-create-genesis from building a hardfork genesis ledger that differs from the chain

A ledger exported to JSON keeps token symbols byte for byte, but a token symbol that is not valid UTF-8 (Mainnet has one, set in block 565083) is replaced with U+FFFD when the file passes through `jq`. mina-create-genesis then built a genesis ledger with a different hash and reported no error. For a Mesa-to-Mesa fork (`--identity-conversion`), it now stops when a ledger's accounts do not hash to the `hash` given in the config, and the hardfork release scripts no longer pass the fork config through `jq`.
