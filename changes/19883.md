Stop mina-create-genesis from building a hardfork genesis ledger that differs from the chain

Token symbols and zkApp URIs are arbitrary bytes on chain, and Mainnet has a token symbol that is not valid UTF-8 (set in block 565083). A fork config must keep such bytes exactly, and a config that was handled as text on the way may not. mina-create-genesis then built a genesis ledger with a different hash and reported no error. For a Mesa-to-Mesa fork (`--identity-conversion`), it now stops when a ledger's accounts do not hash to the `hash` given in the config, and the hardfork release scripts handle the fork config as bytes.
