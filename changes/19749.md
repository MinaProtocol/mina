Add a `scanState` GraphQL query reporting snark work outstanding in each scan state tree

`scanState` returns, for each tree in the scan state, the number of free transaction slots and the number of base and merge snark jobs still to be done — the same numbers as the `slots_available_*`, `base_snarks_required_*` and `merge_snarks_required_*` Prometheus metrics. It reports on the best tip by default, or on any block in the transition frontier given its `stateHash`, and returns the state hash of the block it describes.
