Make the archive hardfork toolbox find the last filled block on the best chain

`mina-archive-hardfork-toolbox fork-candidate last-filled-block` now walks the parent chain from the tip and returns the last block with internal commands on that chain. Before, it returned the highest such block in the whole archive, which could be an orphaned block: a sibling of the fork candidate, or a block of an orphaned branch above it. The tip is the highest block of the archive, or the new optional `--latest-state-hash`.
