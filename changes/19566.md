### Added

- The archive node now reports `Mina_Archive_ingest_duration_ms`, a Prometheus
  histogram of how long it held each block ingest request, labelled by the
  source that sent the block (`diff` for the daemon feed, `precomputed` or
  `extensional` for a block pushed by a client).

  It records how long the archive held a block ingest request: from accepting
  the RPC until the ingest loop took the block off its queue. Because the loop
  handles one block at a time, this is the time the block waited behind blocks
  already being written. It does not include the block's own write, which is
  still logged separately. Each source has its own queue, so `diff` never
  waits behind `precomputed` or `extensional`; they share only the database
  connection pool.

  A daemon that waits longer than the RPC heartbeat timeout gives up and
  drops the block. This metric is the span the daemon waits for, so it shows
  that situation approaching instead of only its result: a gap in the archive.

  It needs `--metrics-port`. Without that flag the archive behaves exactly as
  before.

### Changed

- With `--metrics-port` set, the archive's metrics endpoint now starts
  answering before the genesis ledger is imported rather than after it, and
  it also starts when the archive cannot connect to PostgreSQL.
