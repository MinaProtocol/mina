The `mina-devnet-config` and `mina-mainnet-config` packages include the genesis ledger files

The config packages, and the Docker images built from them, now put the genesis, staking and next epoch ledger tarballs of the network into `/var/lib/coda`. A daemon that starts from a clean state no longer downloads them from S3. The packages are larger: about 285 MB for mainnet and 111 MB for devnet.
