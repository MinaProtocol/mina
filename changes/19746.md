archive_hardfork_toolbox: `settle-pending-blocks` replaces `convert-chain-to-canonical`

The new command settles the pending blocks a hard fork leaves with the same code the archive runs when it adds a fork genesis. It takes `--fork-genesis-hash` (default: the newest fork genesis) and `--dry-run`, and prints JSON. `convert-chain-to-canonical` and its `--target-block-hash`, `--fork-height`, `--protocol-version`, `--stop-at-slot` and `--json` flags are removed.
