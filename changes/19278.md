Fix the genesis ledger cache silently reusing a ledger built with a different `add_genesis_winner` setting. Changing that setting, or changing the proof level while it is unset, altered the ledger's contents but not its cache filename, so a node with an existing cache kept loading the old ledger and computed a different chain id than a node building the ledger fresh — leaving the two unable to peer, with nothing in either node's logs to indicate it. Genesis ledgers cached by an earlier version are rebuilt rather than reused.
