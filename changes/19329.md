- `rosetta-client` gains the Rosetta Construction API: `derive`, `preprocess`,
  `metadata`, `payloads`, `parse`, `combine`, `hash` and `submit`.

- A `--*-json` payload is checked before it is sent: it must parse, it must match
  the Rosetta model its endpoint expects, and every field in it must be one the
  model recognises, so a misspelled field is named rather than silently dropped.
  The free-form `--metadata-json` and `--options-json` must be JSON objects.
  A rejected payload is reported with the name of the offending flag instead of
  as a server error.
