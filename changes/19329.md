- `rosetta-client` gains the Rosetta Construction API: `derive`, `preprocess`,
  `metadata`, `payloads`, `parse`, `combine`, `hash` and `submit`.

- A `--*-json` payload is checked against the Rosetta model that its endpoint
  expects before it is sent, so a malformed request is reported with the name of
  the offending flag instead of as a server error.
