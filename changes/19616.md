ITN GraphQL: caller handles, createAccounts, scheduledTransactions, commitId

The daemon's ITN GraphQL server has four additions for load-testing harnesses. `schedulePayments` and `scheduleZkappCommands` take an optional `handle` (a UUID); a request with the handle of a running scheduler starts nothing and returns that handle. The new query `scheduledTransactions` lists the handles of the running schedulers. The new mutation `createAccounts` creates and funds accounts from a fee payer, like `mina advanced itn-create-accounts`, and returns the keys at once while the funding runs in the background under a handle. `ItnAuth.commitId` reports the daemon's build.
