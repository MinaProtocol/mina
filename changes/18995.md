Add unstaking: accounts can opt out of staking

Delegating to the empty public key now unstakes an account, and newly created accounts start with no delegate instead of delegating to themselves. The chain tracks the total staked supply, and the block producer VRF threshold is computed against staked supply instead of total currency, as described in MIP-0010. `runtime_genesis_ledger` gains a repeatable `--unstake-pk` flag that unstakes the given accounts when generating a fork ledger.

GraphQL exposes the new totals as `consensusState.totalStake` and `epochLedger.totalStake`, next to the existing `totalCurrency` fields. The archive node records them in new `blocks.total_stake` and `epoch_data.total_stake` columns; existing archives must run `upgrade_to_unstaking.sql` (rollback: `downgrade_from_unstaking.sql`), and rows archived before the upgrade keep `NULL` there.
